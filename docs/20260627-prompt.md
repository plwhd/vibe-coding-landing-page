## 网页/活动页表现层优化prompt

输入：请根据以下设计规范顺序对网页进行调整。

1. 视觉定位：先判断页面应该“像什么”。
   1. 类型
   2. 气质
   3. 避免
2. 页面视觉主线：确定页面靠什么形成记忆点。解决页面节奏问题。
   1. 首屏
   2. 中段
   3. 核心区
   4. 底部
3. 色彩系统
   1. 背景色
   2. 主色
   3. 辅助色
   4. 强调色
   5. 中性色
4. 字体与字号层级
   1. H1：
   2. H2
   3. H3
   4. Body
   5. Meta
   检查点：标题是否一眼能扫到？正文是否太长？卡片标题和正文是否区分明显？移动端标题是否过大导致换行难看？
5. 信息密度与文本长短
   1. 判断标准：用户是否能 3 秒内知道页面价值？每张卡片是否 1 眼能看懂？有没有一段话超过 3 行还不是必要内容？
6. 布局节奏：解决模块之间的“呼吸感”。
   1. 重点是强弱变化。
   2. 需要避免的问题：每个模块都是卡片，页面会疲劳；每个模块都居中，页面会单调；每个模块都大标题，层级会失控；间距忽大忽小，页面会显得不专业
7. 组件质感
   1. 解决卡片、按钮、hover、阴影、圆角
8. 移动端体验
   1. 避免出现溢出、拥挤、遮挡和难读
