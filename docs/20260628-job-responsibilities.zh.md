## 前端开发工程师
上海/杭州/深圳/西安
工作职责：
参与核心产品的前端开发工作。
探索技术前沿，参与前端架构演进、组件库建设、工程化工具链优化，探索和应用新技术落地，提高开发效率和质量。
驱动产品创新，从前端技术视角出发，为产品设计和技术创新提供新思路和解决方案。
岗位要求：
本科以上学历,毕业2年以内或应届。
有基本的web前端基础知识和开发经验，包括但不限于 HTML、CSS、JavaScript/TypeScript、HTTP 协议、浏览器等。
了解前端工程化（如 Webpack），熟悉至少一个前端主流框架或库（如 React、Vue、Angular 等）。
有一定的工程实践经验，有良好的编码规范和习惯，熟悉 Git、Lint 等工具。
有良好的计算机基础和技术发展潜力，有优秀的逻辑思维能力和解决问题的能力，能快速熟悉并掌握新技术。
有良好的沟通协调能力，并且有责任感、有自驱力。
加分项
爱折腾、有好奇心，热爱编程，关注前沿技术，是活跃的 Github 用户并且有开源贡献，或参与技术分享。
了解或使用过至少一种后端语言，如 Go、Python、Java、C++ 等
熟练使用 AI 编程助手（如 Copilot、Cursor、Claude Code 等）提升开发效率。
有良好的英语水平和阅读习惯
